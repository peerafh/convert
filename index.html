Link for your shortcut

https://peerafh.github.io/convert/?q=

iPhone

  1. In Shortcuts, make a new shortcut called Convert.
  2. Add URL Encode, then Text with the link above followed by the URL Encoded Text, then Show Web Page.
  3. Turn on Show in Share Sheet. Set it to receive Text, and choose Get Clipboard if there's no input.
  4. Optional: Settings › Accessibility › Touch › Back Tap › Double Tap › Convert.

Mac

  1. Make the same shortcut, but end it with Open URLs instead of Show Web Page.
  2. In its details, turn on Use as Quick Action and Services Menu, and add a keyboard shortcut.
